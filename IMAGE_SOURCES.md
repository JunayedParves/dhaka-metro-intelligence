## Notes

- CC BY-SA 4.0 and CC BY 4.0 require attribution; CC BY-SA also requires that adapted versions be shared under the same licence. Keep this file and the on-screen credits if the dashboard is redistributed.
- Each image was checked visually. The Mirpur 10 image comes from the Mirpur 10 station category, but the signage in the frame is too small to confirm independently.
- Several images show interiors or platforms because those were the clearest available for that station.
- If a photograph fails to load, the dashboard shows a labelled illustrative placeholder instead of another station's picture.
